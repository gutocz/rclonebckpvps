Integração pessoal de backup

Rclone Backup VPS

Uma automação privada para enviar backups criptografados de bancos de dados a uma conta Google Drive controlada pelo próprio administrador.

Acesso limitado

Utiliza o escopo drive.file, restrito aos arquivos e pastas criados pela própria integração.

Criptografia local

O conteúdo e os nomes dos arquivos são criptografados pelo Rclone antes de serem enviados.

Uso particular

Não é um serviço público e não oferece cadastro ou acesso para terceiros.
